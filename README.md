# PDF Signer ✍️

A dead-simple, browser-based PDF signing tool.

- No installs.
- No dependencies.
- Just open `index.html` and sign your PDF.

## Features

- Load any PDF.
- Type your signature (customizable fonts coming soon!).
- Place your signature wherever you want.
- Save the signed PDF.

## How to Use

1. Download index.html

2. Open index.html in your browser.

3. Upload a PDF, type your signature, place it, and save!
